Student Profile

A master-detail layout for editing student records — identity, information, and two guardian contacts structured into a clear, scannable form.

Year 2026
Role UI/UX Designer
Tools Figma / HTML/CSS
Type Web Application / Form Design
Overview Structure Live Preview

Overview

Organising complex data

Student record management involves multiple data types — identity numbers, personal details, and contact information for two separate guardians. The design challenge was grouping these clearly so administrators can find and edit the right field quickly, without scrolling through an undifferentiated wall of inputs.

The master-detail layout keeps the student's summary visible while the edit panel shows the full field set, grouped into named sections with clear visual separation.

Structure

Four sections, one form

Student Identity Student Information Primary Contact Secondary Contact

Each section is visually distinct but part of a single continuous form. Required and optional fields are clearly marked. Guardian contact sections follow an identical structure — reducing cognitive load when entering information for a second contact.
