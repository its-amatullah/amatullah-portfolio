Design Gallery

A lightweight system for publishing, organising and sharing live HTML design prototypes — built with Python and deployed on GitHub Pages.

Role Designer & Builder
Tools Python / GitHub Pages / HTML/CSS

Overview The Problem The System Features Live Preview

Overview

Design work that's easy to share

When working across multiple product modules and collaborating with a development team, sharing design prototypes becomes a friction point. Sending files back and forth, managing versions, and giving developers a reliable way to preview and review designs takes time away from actual design work.

The Design Gallery is a system I conceptualised and built to solve this — a searchable, filterable, version-aware gallery of live HTML design prototypes, automatically generated and published to a URL the whole team can access without any login or tool subscription.

The Problem

Scattered prototypes, unclear versions

HTML design prototypes were accumulating across local folders, email threads, and shared drives. There was no single source of truth for which version of a design was current, no way to browse all active work at once, and no reliable preview URL to give a developer for review.

The workflow needed to be low-friction enough to stay up to date — not a CMS that requires careful maintenance, but something that updates automatically when a new prototype is added to the folder.

The System

How it works

01

Prototype folder

Each design lives in a named subfolder under designs/. Adding a new folder with an HTML file is all that's needed to register a new project.

02

Python generation script

A Python script walks the designs folder, reads metadata (module name, developer, dates), and generates the gallery index HTML. Running the script takes seconds and produces a ready-to-deploy page.

03

GitHub Pages deployment

The output is committed to a GitHub repository and served via GitHub Pages — giving every prototype a stable, shareable URL. No server, no build pipeline, no hosting cost.

04

Team access

The gallery is password-protected for internal use. Developers, product managers, and stakeholders get a single URL — no tool access or account needed to browse and preview designs.

Features

Built for a design workflow

Search & filter

Search by project name, module, or developer. Results update instantly as you type.

Sort by date

Sort by upload date or last modified — always surface the most recent work first.

Multiple previews per project

A single project card can link to multiple HTML files — useful for before/after comparisons or multi-screen flows.

Password protection

Gallery-level password gate keeps internal work private without requiring individual file protection.

Prompt library

A companion page housing audit prompts and design review rules — useful for structured developer or QA handoffs.

Archive

Completed and inactive prototypes moved to an archive section — keeping the active gallery clean without losing history.
