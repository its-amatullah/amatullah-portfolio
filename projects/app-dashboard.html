App Activity Dashboard

A monitoring dashboard surfacing activity and engagement metrics across a multi-school platform — built for administrators who need fast answers at a glance.

Year 2026
Role UI/UX Designer
Tools Figma / HTML/CSS
Type Web Application / Dashboard
Overview Scope Live Preview

Overview

Data that's easy to act on

This dashboard was designed to give platform administrators a clear, real-time view of activity and engagement across a large number of schools. The challenge was data density — surfacing meaningful metrics without overwhelming the user with noise.

The design uses a familiar left sidebar navigation pattern, a persistent search bar, and a filterable main content area. Each key metric is surfaced in a scannable card layout with consistent visual weight.
